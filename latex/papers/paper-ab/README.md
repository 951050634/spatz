# Paper A+B: Interface-Preserving Online Softmax Merge Offload

This directory contains the combined Paper A+B draft:

```text
paper_ab.tex
```

The draft presents the restricted-semantics integration prototype as Phase A
and the complete mixed-scalar merge datapath as Phase B. It should be treated
as a system-prototype paper draft, not as an end-to-end attention accelerator
claim.

Build from this directory with:

```bash
latexmk -pdf paper_ab.tex
```
