# 论文主线、结构与完成计划

## 1. 论文论点

建议身份句：

> 本文通过 A0/A1/A2 的可复现实测，研究 online softmax merge 在 cluster-local
> 专用硬件与 RISC-V 向量核之间的执行边界，并证明 scalar recurrence offload
> 与 RVV vector update 的组合优于将两者全部放入当前 SMU。

标题暂不冻结。可围绕以下方向拟定：

> Finding the Right Offload Boundary for Online Softmax Merge in a
> RISC-V Vector Cluster

## 3. 推荐章节结构

### 3.1 Introduction

先写问题而不是实现清单：online merge 同时包含低并行的 scalar recurrence 和高
并行的向量更新，盲目整体卸载可能用较慢的数据通路替代已有 RVV。随后给出本文的
执行边界、三类实现和核心结果。

### 3.2 Background and Motivation

只保留理解 recurrence 和 Spatz/TCDM 边界所需的背景。用 B2-R/B3 周期模型提出
矛盾：Full SMU 消除了每行成本，但引入了更高的每元素成本，因此需要 A1。

### 3.3 Design

按数据流组织：MMIO 提交、scalar recurrence、权重写回、RVV update、错误与边界。
Full SMU 作为消融模式介绍，不再作为默认最优设计。

### 3.4 Methodology

说明相同输入和数值语义、warm-up/repeats、median、RVV 反汇编门槛、正确性门槛、
clean provenance，以及 functional-simulation cycles 的边界。

### 3.5 Evaluation

按问题顺序展开：

1. Full SMU 相对公平 RVV baseline 是否获益？
2. 收益来自 scalar 还是 vector？
3. 哪个阶段成为新瓶颈？
4. TCDM 并发是否改变该解释？
5. 当前实现是否满足被测数值正确性？

### 3.6 Related Work

围绕三类最近邻组织：online/blockwise softmax、softmax/attention 专用硬件、
RISC-V/PULP scratchpad-coupled accelerator。必须逐篇核验 FuseMax、Flexible
Template、ITA 和 Softermax 的全文，再决定 C1 的最终措辞。

### 3.7 Limitations and Conclusion

主动声明本文不是完整 attention accelerator，不提供物理 PPA，也不证明固定 LUT
全局最优。结论回到异构执行边界，而不是泛化为“硬件总是优于软件”。

## 5. 剩余必要工作

### P0：形成可投稿论证

1. 将当前 A1 实现和 runner 变更整理为明确 commit；
2. 在 clean commit、同一 CFG 和同一 simulator 身份上复跑三个 A1 anchor；
3. 精读并核验四篇最高风险 closest prior art；
4. 按本文件的主线重写论文 Introduction、Design 和 Evaluation；
5. 生成三张核心图，并从结构化结果自动导出；
6. 做一次 claim-evidence 审计和模拟审稿。

### P1：仅在审稿风险要求时补充

- 增加少量 A1 规模点，用于更准确定位 A1/A2 crossover；
- 对 clean A1 结果增加独立分析器或重复构建验证；
- 补充一个小规模启动开销分解，而不是扩展完整 attention。

### 删除或停止

- blocked-attention / 完整 attention 最小闭环；
- LUT 段数与指数范围 sweep；
- B0/B2-F 自然 `expf` 主矩阵；
- 无物理流程的 ASIC PPA 或功耗估算；
- 已停用的多论文路线和全系统扩展。

## 6. 完成标准

- A1 三点具有 clean source、CFG、simulator、ELF 和结果哈希；
- 每项 headline claim 都能指向一张表、一个图或一项直接代码证据；
- closest prior art 全文核验完成，且不使用无法证明的“首次”；
- 正文只围绕 merge offload boundary，不出现无证据的 attention/LLM 外推；
- 图表中的直接测量、模型拟合和 proxy 明确区分；
- 论文可编译，引用、术语、数字和 artifact 路径一致。
