# A1 标量卸载实验

> 本文件保留 A1 批次的详细数字和 provenance。跨实验的统一解释见
> [实验设计与结果.md](实验设计与结果.md)。

## 1. 实验范围

A1 使用 SMU 执行逐行 scalar recurrence，并把两个 FP32 权重写回 TCDM；现有
RVV kernel 随后执行加权 `O[D]` 更新。三种实现保持输入、数值语义、输出检查、
命令边界和计时窗口一致：

- A0 / B2-R：software scalar recurrence + RVV vector update；
- A1：SMU scalar recurrence + RVV vector update；
- A2 / B3：SMU scalar recurrence + SMU vector update。

实现增加默认 Full 的 mode register，以及 old-weight、tile-weight 两个写回地址。
Mode 0 保持完整 SMU 行为；Mode 1 写回 `m`、`l`、`old_weight` 和 `tile_weight`，
不进入 SMU vector state。

## 2. 端到端结果

实验使用默认 Spatz cluster 配置、seed 1、一次 warm-up 和三个 measured repeats。
36 条目标记录全部通过，`failures.json` 为空。

| `(N,D)` | A0 median | A1 median | A2 median | A1/A0 加速 | A1 相对 A2 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `(1,1)` | 1,975 | 1,436 | 1,348 | 1.38x | 0.94x |
| `(8,32)` | 13,317 | 2,543 | 3,489 | 5.24x | 1.37x |
| `(16,64)` | 27,088 | 4,878 | 9,791 | 5.55x | 2.01x |

“A1 相对 A2”是 `A2_cycles / A1_cycles`。极小规模 `(1,1)` 中，Full SMU 仍
略快；当向量工作量增加后，RVV 较低的每元素成本能够抵消权重写回和 handoff。

## 3. A1 组成周期

两个区间互不重叠。`SMU scalar` 包含寄存器配置、scalar-only 执行、权重写回和
完成轮询；`RVV vector` 是随后的加权向量更新。

| `(N,D)` | A1 median | SMU scalar median | RVV vector median |
| --- | ---: | ---: | ---: |
| `(1,1)` | 1,436 | 1,321 | 115 |
| `(8,32)` | 2,543 | 1,444 | 1,117 |
| `(16,64)` | 4,878 | 1,636 | 3,260 |

每次重复均满足 `smu_scalar_cycles + rvv_vector_cycles = cycles`。各列独立取中位数，
因此表中的三个中位数不要求严格相加。

## 4. 正确性与 TCDM

所有 A1 重复均通过 `1e-3` 正确性门槛。三个点的最大绝对误差分别为
`1.252e-6`、`6.032e-4` 和 `2.594e-4`，与相同输入下的 A0/A2 一致。

| `(N,D)` | TCDM accessed median | TCDM congested median |
| --- | ---: | ---: |
| `(1,1)` | 400 | 1 |
| `(8,32)` | 922 | 1 |
| `(16,64)` | 2,244 | 2 |

该消融隔离了主要体系结构效应：硬件 scalar merge 消除了软件逐行成本，而 RVV 在
两个较大 anchor 上是更好的向量更新路径。因此，当前证据更支持
SMU-scalar/RVV-vector 的异构设计，而不是 Full SMU datapath。
