## 2. A1 三点复跑

从仓库根目录执行：

```bash
cluster="$PWD/hw/system/spatz_cluster"
python3 util/online_softmax_merge/run_experiments.py \
  --repo-root "$PWD" \
  --source-dir "$cluster/sw" \
  --build-dir "$cluster/sw/build" \
  --simulator "$cluster/bin/spatz_cluster.vlt" \
  --cfg "$cluster/cfg/spatz_cluster.default.dram.hjson" \
  --work-dir "$(dirname "$PWD")/work-online-merge-a1-clean" \
  --case 1,1,1,main,1800 \
  --case 8,32,1,main,1800 \
  --case 16,64,1,main,3600 \
  --repeats 3 \
  --jobs 8
```

正式接收门槛：

- `run_manifest.json` 中 `git_dirty=false`；
- 三个 case 均有一次 warm-up 和三次 measured repeats；
- B1、A0/B2-R、A1、A2/B3 共 36 条 measured records 全部为 `pass`；
- `failures.json` 为空；
- RVV disassembly gate 通过；
- 每次 A1 满足 component cycles 与总周期一致；
- 结果趋势与当前验证一致。

## 6. 证据等级

| 等级 | 要求 | 可用于 |
| --- | --- | --- |
| 正式证据 | clean commit、固定 CFG/simulator、完整 manifest 与独立检查 | 论文表图和 headline |
| 验证证据 | 功能与记录全部通过，但 source dirty | 设计决策和结论收敛 |
| 诊断证据 | timeout、tool error、混合 provenance 或不完整窗口 | 定位问题，不报告性能 |
| Proxy | generic cells、零延迟 RTL toggles | 限定范围的复杂度/活动度描述 |

任何模型预测点不得混入直接测量表；任何 proxy 不得改写为物理面积、Fmax、功耗、
能耗或关键路径结论。
