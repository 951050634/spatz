# Online Softmax Merge 实验设计与结果

## 1. 实验逻辑

实验围绕一条因果链组织，而不是罗列功能测试：

```text
公平 RVV baseline
  -> Full SMU 是否获益
  -> 获益来自 scalar 还是 vector
  -> 瓶颈是否由 TCDM 并发/拥塞造成
  -> 结论是否满足数值正确性边界
```

主要性能指标是 Verilator 功能仿真的 target cycles。每个正式点包含一次 warm-up
和至少三次测量，报告 median，并保留 min/max、状态、日志、ELF、CFG、simulator
及哈希。B2-R/A0 必须通过 RVV 反汇编门槛。

## 2. 核心实验：A0/A1/A2

### 2.1 端到端结果

2026-07-20 的 A1 验证使用相同输入、数值语义、正确性门槛和计时窗口。36 条目标
记录全部通过，`failures.json` 为空。

| `(N,D)` | A0 cycles | A1 cycles | A2 cycles | A1/A0 加速 | A1 相对 A2 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `(1,1)` | 1,975 | 1,436 | 1,348 | 1.38x | 0.94x |
| `(8,32)` | 13,317 | 2,543 | 3,489 | 5.24x | 1.37x |
| `(16,64)` | 27,088 | 4,878 | 9,791 | 5.55x | 2.01x |

“A1 相对 A2”定义为 `A2_cycles / A1_cycles`；大于 1 表示 A1 更快。

结论很直接：scalar offload 在三个点均有效；极小规模仍适合 Full SMU，因为额外的
权重写回和 RVV handoff 无法摊薄；中大规模则由 RVV 更低的每元素成本占优。

### 2.2 A1 周期组成

| `(N,D)` | A1 总周期 | SMU scalar | RVV vector |
| --- | ---: | ---: | ---: |
| `(1,1)` | 1,436 | 1,321 | 115 |
| `(8,32)` | 2,543 | 1,444 | 1,117 |
| `(16,64)` | 4,878 | 1,636 | 3,260 |

每次重复都满足 `SMU scalar + RVV vector = A1 cycles`。表中独立取中位数，因此
列中位数在个别情况下可能不严格相加。

### 2.3 正确性与 TCDM

| `(N,D)` | A1 最大绝对误差 | TCDM accessed | TCDM congested |
| --- | ---: | ---: | ---: |
| `(1,1)` | `1.252e-6` | 400 | 1 |
| `(8,32)` | `6.032e-4` | 922 | 1 |
| `(16,64)` | `2.594e-4` | 2,244 | 2 |

三个点均通过 `1e-3` 正确性门槛，且与相同输入下的 A0/A2 误差一致。A1 的 TCDM
congestion 极低，不能解释 A1/A2 的主要差异。

## 3. 支撑实验：B2-R/B3 规模矩阵

B2-R 是 RTL-aligned scalar weights 加 RVV vector update；B3 是 Full SMU。16 个
直接测量点均满足 `B3 cycles <= B2-R cycles`，实测加速为 `1.424x` 至
`10.140x`。

下表格式为 `B2-R / B3 / speedup`：

| `N` | `D=1` | `D=8` | `D=16` | `D=32` |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 1966 / 1124 / 1.749x | 1968 / 1121 / 1.755x | 1995 / 1203 / 1.658x | 1977 / 1388 / 1.424x |
| 2 | 3387 / 1106 / 3.063x | 3426 / 1228 / 2.790x | 3455 / 1351 / 2.557x | 3504 / 1610 / 2.176x |
| 4 | 6739 / 1194 / 5.644x | 6772 / 1436 / 4.716x | 6812 / 1655 / 4.116x | 6867 / 2136 / 3.215x |
| 8 | 13080 / 1290 / 10.140x | 12885 / 1732 / 7.439x | 13078 / 2281 / 5.733x | 13547 / 3263 / 4.152x |

周期模型为：

```text
C(N,D) = C0 + Cs*N + Cv*N*D + Cstall
```

| 实现 | `C0` | `Cs` | `Cv` | `R²` |
| --- | ---: | ---: | ---: | ---: |
| B2-R | 483.353 | 1538.127 | 2.056 | 0.999738 |
| B3 | 1058.654 | 22.029 | 7.995 | 0.999967 |

该模型解释了完整 SMU 的优势和局限：它把每行成本从约 `1538` 降到 `22` cycles，
但每元素成本从约 `2.06` 增加到 `8.00` cycles。A1 正好组合了两者更优的部分。

## 4. 支撑实验：Full SMU 的 FSM 分解

| `(N,D)` | Scalar | Vector | Busy | Scalar/Busy | Vector/Busy | 其他开销 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `(1,1)` | 20 | 9 | 29 | 68.97% | 31.03% | 1,095 |
| `(8,32)` | 160 | 2,063 | 2,223 | 7.20% | 92.80% | 1,040 |
| `(16,64)` | 320 | 8,214 | 8,534 | 3.75% | 96.25% | 1,022 |

FSM 与规模模型相互印证：scalar path 约为 `20 cycles/row`；在中大规模上，继续
优化 scalar nonlinear path 的边际价值很小，当前性能瓶颈是 SMU vector update。
极小规模的主要问题则是约一千周期的提交、同步和等待开销。

## 5. 次要边界证据

### 5.1 TCDM 并发

在 `(N,D)=(16,64)` 的 clean formal concurrency 实验中，C3 的 SMU slowdown 为
`8533/8529=1.000469`，core slowdown 为 `3163/3144=1.006043`，TCDM congestion
为 `73/5765=1.2663%`。16 个 bank phase 的并发总周期中位数为 `10,226`，范围
为 `10,184` 至 `10,235`。

该结果只说明当前单 SMU、单 core stream 和固定规模能够共存；它不证明任意负载
或多引擎扩展都无拥塞。

### 5.2 数值边界

当前实现采用固定 256 段 Q1.23 exponential/reciprocal LUT 与 Q16.32 内部
计算。现有 host model 和 RTL gate 足以证明当前测试输入通过正确性要求。本文不把
LUT 选择写成创新，也不做段数、指数范围或完整 attention 误差传播 sweep。

### 5.3 资源与活动度代理

Yosys-Slang 的 Full SMU synthesis-only scope 为 `94,713` 个 post-techmap
generic cells；该数字是 bit-blasted 结构复杂度代理，不能视为标准单元面积。

在 `(16,64)` 的零延迟 RTL 窗口中，B2-R 与 B3 分别记录 `41,479,210` 和
`12,465,919` 次 known-bit toggles。它们只能说明当前仿真窗口的 RTL 活动度，不能
换算为 mW、pJ 或物理能效。
